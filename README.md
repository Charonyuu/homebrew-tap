# Charonyuu's Homebrew tap

```bash
brew trust charonyuu/tap
brew install --cask charonyuu/tap/prewarm
```

## Casks

| Cask | What it is |
|---|---|
| [`prewarm`](Casks/prewarm.rb) | [Prewarm](https://github.com/Charonyuu/prewarm) (formerly Claude Prewarm) — a macOS menu bar app that starts your AI coding usage windows before you sit down, and shows Claude, Codex, Grok and agy limits in one menu |

`claude-prewarm` was renamed to `prewarm`; `brew upgrade` moves existing installs over.
